# 自動動画メーカー（AutoVideo）

台本を書いて、画像・動画・立ち絵・BGM・SEを置くだけで動画を作れる Windows 用アプリです。
声は **VOICEVOX で読み上げ**、**自分で用意した音声ファイル**、**声なし** の3つから選べます。

## できること

- 画面比率を選べる（16:9、9:16、1:1、4:3、4:5 など）
- 画像フォルダ・動画フォルダの素材を、キャンバスの好きな場所に配置
  - 置いたら **OK** で固定、固定した素材をクリック → **解除** でもう一度動かせる
  - キャンバスは最初は空。自分で置いていきます
- 台本から素材の表示・消去を指定（`[画像:名前]` / `[消去:名前]`）。消すまでは表示され続けます
- 配置タブでもフレームを選んで表示・消去ができる
- 台本は右クリックで切り取り・コピー・貼り付け（命令の挿入もできます）
- 立ち絵と音声があればリップシンク（口パク）
- BGM・SE も画像と同じように、フレームを選んで開始・停止・再生
- 字幕の ON/OFF、文字サイズ・色
- 動画の長さ（秒）を指定（0 = 台本の長さに合わせる）
- 素材のない場所の背景色をカラーパレットで選べる
- プレビューは動画で（別ウインドウ）
- 保存（Ctrl+S）して後で再編集。2分ごとに自動で一時保存
- **まとめて保存**：外部の素材もプロジェクトフォルダにコピーして一式保存（ZIP も作れます）
- **書き出し**：完成した動画（MP4）をプロジェクトフォルダに保存

## 使い方（かんたん）

1. Python 3.10 以上を入れる（https://www.python.org/ ・インストール時に「Add python.exe to PATH」にチェック）
2. このフォルダの **`run.bat`** をダブルクリック（初回は数分セットアップします）
3. VOICEVOX を使う場合は、先に VOICEVOX を起動しておく

exe を作りたいときは `build_exe.bat` を実行すると `dist\AutoVideo\AutoVideo.exe` ができます。
GitHub の Actions タブ（Windows build）からビルド済みの exe をダウンロードすることもできます。

## サンプル

`サンプル` フォルダに、すぐ試せるサンプルプロジェクトが入っています（キャラクター「まる」、画像、動画、BGM、効果音つき）。
アプリの **ファイル → サンプルを開く** で、ドキュメントフォルダにコピーして開きます（初回起動時にも聞かれます）。
最初は「声なし」になっています。VOICEVOX を起動して音声を「VOICEVOX」に切り替えると、まるが喋って口パクします。
サンプルの素材はすべてこのアプリ用に作ったもので、自由に使えます（`tools/make_sample.py` で作り直せます）。

## プロジェクトフォルダ

新規作成すると、次のフォルダができます。ここに素材を入れると一覧に出ます（エクスプローラーからドラッグでも追加できます）。

```
動画_20261125/
├─ project.avmproj   ← プロジェクトファイル
├─ 画像/  動画/  立ち絵/
├─ BGM/   SE/   ボイス/
└─ 動画_20261125_xxxxxx.mp4   ← 書き出した動画
```

## 台本の書き方

1行 = 1フレーム（1場面）です。

```
[画像:ずんだもん][BGM:bgm.mp3]
ずんだもん：こんにちは、ずんだもんなのだ！
[画像:ねこ][SE:ぽん.wav]
今日はねこの話をするのだ。
[消去:ねこ]
[秒数:2]
四国めたん「よろしくね」
[BGM停止]
```

| 書き方 | 意味 |
|---|---|
| `名前：セリフ` / `名前「セリフ」` | 立ち絵の名前で話者を指定 |
| `[画像:名前]` | 画像・動画・立ち絵を表示（名前は配置タブの素材名） |
| `[消去:名前]` / `[全消去]` | 消す |
| `[BGM:ファイル名]` / `[BGM停止]` | BGM 開始（ループ）・停止 |
| `[SE:ファイル名]` | 効果音を1回鳴らす |
| `[音声:ファイル名]` | その行の音声ファイルを指定 |
| `[秒数:3]` | 行の長さを指定。単独の行ならセリフなしで待つ |
| `# メモ` | コメント（無視されます） |

命令は、その行または次のセリフ行の頭で実行されます。

### 音声の3つのモード

- **VOICEVOX**：台本のセリフを VOICEVOX が読み上げます。立ち絵ごとに話者を変えられます（③立ち絵・音声タブ）。
- **用意した音声ファイル**：`ボイス` フォルダに `001.wav`, `002.wav` … と入れると、セリフの順に自動で割り当てます。行ごとに `[音声:ファイル名]` で指定もできます。

- **声なし**：声を入れず、BGM・SE・字幕だけで動画を作ります。各行の長さは文字数から自動で決まります（`[秒数:3]` で指定も可）。

声がある場合、セリフの長さは音声の長さに合わせて自動で決まります。

## 仕組み（開発者向け）

- Python + PySide6（画面）+ FFmpeg（imageio-ffmpeg で同梱）
- `avm/script.py` 台本の解析、`avm/timeline.py` タイムライン・音声ミックス・リップシンク、
  `avm/renderer.py` フレーム描画と書き出し、`avm/ui/` 画面
- テスト: `python -m pytest tests`
